# Інструкції для AI-агента

## Корисні матеріали
У папці `docs/devops-exercises/` знаходяться навчальні матеріали з DevOps, Docker, CI/CD та Git. 
Якщо тобі потрібно написати Dockerfile, налаштувати GitHub Actions або згадати синтаксис Git, 
спочатку переглянь цю папку. Не змінюй файли в цій папці, лише читай їх.

## Архітектурні рішення
Перед будь-якою зміною бекенду чи клієнта прочитай `docs/DECISIONS.md` (ADR) та `docs/BACKEND_PLAN.md`.
Рішення ADR обов'язкові: гість — Supabase Anonymous Sign-In; фото — тільки Signed Upload URL (без base64);
жодних полігонів мінної небезпеки; оплата — RevenueCat; розпізнавання — тільки локальний ONNX, без серверних запитів.
