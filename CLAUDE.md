# Інструкції для AI-агента

## Корисні матеріали
У папці `docs/devops-exercises/` знаходяться навчальні матеріали з DevOps, Docker, CI/CD та Git. 
Якщо тобі потрібно написати Dockerfile, налаштувати GitHub Actions або згадати синтаксис Git, 
спочатку переглянь цю папку. Не змінюй файли в цій папці, лише читай їх.
