# Фото Топ-20 грибів (webp)

База фотографій топ-20 грибів у форматі WebP (якість 85, оригінальна роздільність).

- 20 папок — по одній на кожен вид гриба (Українська назва + латинська).
- У кожній папці: фотографії `.webp` та `опис.txt` з характеристиками виду.
- `поширення.txt` — ареали поширення грибів.

Нумерація імен: колізії вихідних імен (напр. `large.jpg` і `large.jpeg`)
вирішені суфіксами — `large.webp`, `large_2.webp`.

Джерело (оригінали jpg/jpeg): папка `фото Топ-20 грибів` поруч.
Конвертація: `довідник\convert_top20_to_webp.ps1` (ImageMagick, `-quality 85`).
