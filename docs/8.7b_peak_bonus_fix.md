# 8.7b Peak Bonus Duplicate Fix

## Проблема

Два бонуси +0.05 за один і той самий факт
(`ctx.wave ∈ rule.peakWaves`):

1. `rule4_Waves` (`supabase/functions/_shared/forecast/rules.ts`) —
   хардкод-гілка `if (rule.peakWaves.includes(ctx.wave)) mod += 0.05`
2. `scorer.ts` (8.4a) — керований flag `peak_wave_bonus_enabled`
   (`PEAK_WAVE_BONUS = 0.05`)

Сумарно **+0.10 замість +0.05** за один факт.

Симптом: у `matched` білого гриба — reason
`"Осіння хвиля (пік) + peak"` (один reason від rule4 з суфіксом),
а скор містить подвійний peak-бонус.

## Рішення (2026-10-12, варіант A)

Прибрати peak-гілку (+0.05) з `rule4_Waves`.
Залишити тільки бонус у `scorer.ts` через flag
`peak_wave_bonus_enabled`.

```ts
// було
if (rule.peakWaves.includes(ctx.wave)) { mod += 0.05; reason += " + peak"; }
// стало — чиста таблиця клімату
export const rule4_Waves: DynamicRule = (_rule, ctx) => {
  const entry = WAVE_MODIFIERS[ctx.wave];
  return { modifier: entry.mod, reason: entry.reason };
};
```

Обґрунтування:

- Зберігає живий kill-switch (flag), який можна вимкнути одним
  SQL-UPDATE без деплою — узгоджено з філософією `feature_flags`
  (`region_filter_enabled`, `rule5_anti_double_counting_enabled`)
- Уникає другого мертвого флагу (після `gdd_enabled`, ticket з 8.7a)
- `WAVE_MODIFIERS` стає чистою таблицею клімату хвиль
  (single source без спеціального випадку)
- Регресійний тест у `scorer.test.ts` («peak wave bonus → +0.05»)
  лишається значущим — саме він ловить майбутнє подвійне нарахування

## Відхилення від плану v6.0

§12.4 документує rule4 = +0.20 (autumn 0.15 + peak 0.05).
Свідоме відхилення — див. аргументи вище. Щоб повернути
планове значення, потрібно увімкнути обидва механізми, що й
спричинило дублювання.

## Вплив на скори

Для виду з `ctx.wave ∈ rule.peakWaves` (наприклад білий, восени):

| flag `peak_wave_bonus_enabled` | Було | Стало |
|---|---|---|
| `true` (default) | 0.15 + 0.05 + 0.05 = **+0.25** | 0.15 + 0.05 = **+0.20** |
| `false` | 0.15 + 0.05 = **+0.20** | 0.15 = **+0.15** |

- `reason` у `matched`: `"Осіння хвиля (пік) + peak"` → `"Осіння хвиля (пік)"`.
- Інші хвилі (spring/summer1/summer2/late) не змінюються:
  climate 0.05 без peak-гілки = як раніше без флагу.
